# Frontend — Red social

Aplicación en Angular. Ver el [README principal](../README.md) para correrla.

## Estructura

- `core/`: servicio de autenticación, modelos y manejo de errores de la API.
- `shared/`: modal (en lugar de `alert()`), íconos, avatar y validadores.
- `layout/`: barra lateral y navegación.
- `pages/`: login, registro, publicaciones y mi perfil.

La URL del backend se configura en `src/environments/`.
